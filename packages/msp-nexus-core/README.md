# MSP Nexus Core

Original GPL-2.0-or-later companion plugin providing portable MSP content types, Nexus Studio, conditional block layouts, responsive controls, dynamic data and loops, starter profiles, JSON portability, client branding, performance and integration consoles, optional WooCommerce presentation, safe onboarding/reset, diagnostics, licensing, and signed-update support. Public content remains available when licensing or the remote service is unavailable.
