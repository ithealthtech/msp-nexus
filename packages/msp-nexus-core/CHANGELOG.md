# Changelog

## 0.5.1 — 2026-09-24

- Version aligned with the MSP Nexus 0.5.1 theme. No functional changes.

## 0.5.0 — 2026-09-23

- Complete MSP website one-click setup, Company content menu and overview, reorganized and reachable Settings, pages keep their address over content-type listings, and the button-radius token only applies when changed.

## 0.4.0

- Expanded Nexus Studio workspace, revisions, responsive geometry, element conditions, dynamic data/ACF selection, advanced queries, and visual loop layouts.
- Added more than 200 MSP compositions, new interactive/media blocks, advanced header/menu/popup behavior, 36 WooCommerce template elements, and six optional Elementor widgets.
- Added the searchable 800-kit starter catalog, single-content portability, consent management, expanded white labeling, modern image controls, and integration diagnostics.
- Remains compatible with PHP 7.4.33 and newer.

## 0.3.0

- Added Nexus Studio, 30 MSP element variations, responsive block controls, conditional layouts, dynamic values, general content loops, reusable layout regions, mega-menu panels, and popup triggers.
- Added four starter-site profiles, safe JSON portability, client white-labeling, integrations guidance, global design controls, and a performance console.
- Added optional WooCommerce theme support, product dynamic data, HPOS declaration, and Product Showcase block.
- Remains compatible with PHP 7.4.33 and newer.

## 0.2.0

- Added production-safe publish/draft handling, site-name-aware homepage imports, complete Contact and Support starters, and launch-safety diagnostics.
- Unverified demo proof and legal placeholders now remain drafts until reviewed.
- Remains compatible with PHP 7.4.33 and newer.

## 0.1.0

- Initial development release with thirteen content types, six taxonomies, five dynamic blocks, settings, onboarding, diagnostics, schema, licensing, and verified-update client.
- Compatible with PHP 7.4.33 and newer; update preflight and diagnostics enforce the same floor.
