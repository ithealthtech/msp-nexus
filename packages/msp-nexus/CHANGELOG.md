# Changelog

## 0.4.0

- Added presentation support for the expanded Nexus Studio element, responsive, header, consent, commerce, and adaptive starter systems.
- Retains the portable native block architecture, four visual systems, original pattern library, and PHP 7.4.33 floor.

## 0.3.0

- Added three additional original homepage starters for security, co-managed IT, and cloud/innovation firms.
- Added presentation support for Nexus Studio elements, responsive controls, reusable regions, and WooCommerce-aware blocks through the companion plugin.
- Remains compatible with PHP 7.4.33 and newer.

## 0.2.0

- Improved the default homepage, footer, CTA routing, archive semantics, and metadata for production use.
- Removed fictional brand and proof content from public patterns and added a complete About page pattern route.
- Remains compatible with PHP 7.4.33 and newer.

## 0.1.0

- Initial development release with native block templates, style variations, pattern library, responsive design system, and companion-plugin integration.
- Compatible with PHP 7.4.33 and newer.
