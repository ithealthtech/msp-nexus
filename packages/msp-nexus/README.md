# MSP Nexus theme

Original GPL-2.0-or-later block theme for MSP and technology-service sites. Requires WordPress 6.7 or newer and PHP 7.4.33 or newer. It includes native templates, editable template parts, four style variations, a 60+ pattern library, responsive global styles, RTL support, and a child-theme customization path. MSP Nexus Core is optional and adds structured content, dynamic blocks, onboarding, diagnostics, and commercial update access.
