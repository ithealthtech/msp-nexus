# Optional plugins

MSP Nexus has no required paid plugin. Add plugins only for a real operational need and validate each on staging.

- WooCommerce: optional product, cart, checkout, and account workflows.
- One established SEO plugin: optional advanced schema, sitemap, and editorial tooling. Built-in schema yields when Yoast SEO, Rank Math, or All in One SEO is detected.
- One established forms platform: Gravity Forms, Fluent Forms, Contact Form 7, or WPForms. Theme styles are presentation compatibility only.
- WPML or Polylang: optional multilingual operation; validate language-specific templates and URLs.
- A host-compatible caching/image optimization solution, security monitoring solution, backup solution, SMTP provider, and consent platform selected for the deployment's jurisdiction and infrastructure.

Do not install overlapping SEO, caching, security, or forms suites. MSP Nexus never installs plugins remotely or bundles paid extensions.
