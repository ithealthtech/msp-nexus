# Product accessibility statement

MSP Nexus is engineered toward WCAG 2.2 AA for its supplied theme interfaces and original blocks. It uses semantic landmarks, a skip link, visible focus, core WordPress navigation behavior, labeled form controls, status messages, disclosure elements, no-JavaScript filtering, responsive reflow, reduced-motion handling, and tested color contrast.

Conformance of a deployed customer site is not guaranteed: edited colors, copy, media, navigation, third-party plugins, embeds, forms, and content can introduce barriers. Site owners must test representative journeys with keyboard, zoom/reflow, screen readers, reduced motion, high contrast, validation errors, and multiple browsers before launch and after material changes.

Known boundary: automated checks cannot prove usability or complete conformance. The final validation report records the tested package and remaining manual review obligations.
