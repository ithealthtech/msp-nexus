# Editor guide

Activate MSP Nexus and MSP Nexus Core, then open Appearance → Editor. Global colors, type, spacing, button treatment, templates, headers, and footers remain native Site Editor controls. Choose one of four style variations: Enterprise Dark, Clean Corporate Light, Cybersecurity, or Cloud & Innovation.

The pattern inserter exposes 48 reusable MSP sections, 12 full page starters, alternate headers/footers, and a services mega-panel pattern. Patterns are ordinary editable blocks. Dynamic Service Grid, FAQ List, Breadcrumbs, and Consultation Form blocks read site-owned content from the companion plugin.

Use Services, Industries, Case Studies, Locations, Testimonials, Team, Resources, and FAQs in the dashboard for reusable structured content. Deactivating or losing a commercial entitlement does not delete these records.

## Nexus Studio

Open **MSP Nexus → Studio** for direct routes to the visual Site Editor, pattern library, Navigation, reusable layouts, starter profiles, and portability tools. On a public page, use **Inspect in Nexus Studio** in the signed-in toolbar to outline visible regions and open the correct editor. Inspection mode never writes to the page.

The block inserter includes more than 200 original MSP compositions, 36 WooCommerce template variations, and 22 server-rendered blocks for dynamic values, content loops, layouts, navigation, media, interaction, metrics, tables, forms, and commerce. Ordinary blocks receive optional per-device geometry, position, transforms, type, display, visibility, and reduced-motion-aware entrance controls plus visitor/content/date/query display rules.

Use **MSP Nexus → Nexus layouts** for reusable block compositions. Set an area, display context, optional post type, and priority in the layout rule panel. Drafts have no public effect. Full-template layouts should contain a header template part, a `main` group with Post Content or an archive/query composition, and a footer template part. Header and footer rules replace matching template-part areas. Mega-menu and loop layouts are rendered with their dedicated blocks. Popup layouts support delay, scroll-depth, exit-intent, and click-selector triggers with a dismissal period.

Use **Starter sites** to search 800 configurations by industry, service focus, and visual system. Design tokens, missing draft pages, a new front page, an existing Nexus-owned homepage, and reusable navigation are applied independently. Non-Nexus pages are not overwritten.

Use **Import / export** to move reviewed settings, layouts, current-theme templates/parts, Nexus-owned starter pages, or one focused page/content document. Test imports on staging and opt into each content class explicitly.

Before launch:

- review every draft sample person, company, claim, metric, address, phone, testimonial, partner mark, resource, event, and legal placeholder before publication;
- obtain permission for customer stories, logos, portraits, and testimonials;
- provide accurate alt text based on the actual editorial purpose;
- test keyboard navigation, focus, forms, menus, mobile layouts, reduced motion, RTL, and long translations;
- connect a reviewed privacy policy, mail delivery, spam controls, consent platform, analytics, SEO plugin, and form/calendaring integrations only as needed.
